## Smart Street Light System (kanyakumari district)
An IoT-based energy-efficient street lighting solution that automates brightness based on vehicle movement and ambient light levels.
## 🚀 Features

* Dynamic Dimming: Lights dim automatically when roads are empty.
* Motion Detection: Sensors brighten lights instantly when vehicles approach.
* LDR Integration: System turns off automatically during daylight hours.
* Energy Monitoring: Tracks power consumption data in real time.
